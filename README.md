#### NovaEngine





NovaEngine is a C++ Game engine, but for now it's mostly only graphics stuff. This project is made entirely by me and has taken me four months to make.

This will probably not be the last version but it might take a while for the next version to come out because I don't understand what the hell I wrote.



1. Features
- Windows
- Input system
- DeltaTime
- Vector2
- Vector3
- Transform (position, rotation and scale)
- VAO (VertexArrayObject)
- VBO (VertexBufferObject)
- IBO (IndexBufferObject)
- VertexLayout
- Shader (class)
- Texture support
- Mesh class
- Camera
- static Renderer

All of these are explained inside Doc.md.

2. Requirements / Dependencies
NovaEngine uses these libraries:
- OpenGL for graphics
- GLAD 1.0.36 to load GL functions 
- GLM for various math functions.
The project is currently compiled on Windows. Other platforms have not been tested.

3. Project status
NovaEngine is currently at v0.1.0.

Expect bugs, unfinished features, and questionable code. Development is ongoing, but future releases might take some time as I continue learning, improving the engine, and trying to understand some of my own code.
